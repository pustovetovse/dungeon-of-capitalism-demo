# Dungeon of Capitalism — запись мира

Сайт: https://pustovetovse.github.io/dungeon-of-capitalism-demo/

Экономическая игра про город у входа в подземелье. Здесь — запись одного мира (сид 7,
10 лет) и проигрыватель: время идёт само, ползунок переносит в любой день записи. Всё
собрано из ветки интерфейса игры автоматически; репозиторий игры — отдельный.

Атрибуция внешних библиотек, шрифтов и иконок — на странице, кнопка «Об игре»;
лицензии библиотек — в `vendor/*/LICENSE` и `NOTICE`.
